## 待处理

- 群系表档位由 `tuning.LEGACY_BIOME_TIER` 控制，当前 `balanced`（1.16.5 1044 条、1.17.1 1046 条）。`full` 与 `lite` 也已生成，改旋钮后重建即可切换。旧版群系查找是线性扫描，档位决定每区块开销。
- 旧版群系源采样恒在 `y=0`，洞穴群系只能占一个地表点位。1.17.1 的 `dripstone_caves` 落在高海拔、`lush_caves` 落在湿润带；若要把它们放回地下，需要重写初始密度公式，不属本次迁移范围。
- 1.20.2 ~ 1.20.6 由 `pack.mcmeta` 的 `supported_formats` 覆盖（`15` ~ `41`），1.20 与 1.20.1 只读 `pack_format`（`15`）。需在 1.20.2 与 1.20.5 实机确认包被识别为兼容。
- 1.18.2 的 `offset` 与 `jaggedness` 点集取自 1.19，已做结构与逐叶的静态核对，仍需实机逐区块比对。1.20 与 1.19 的对应产物逐字节相同，同一批点集同样待实测。1.19 的点集已由 `1.19-pre1` dump 与 `1.19.3` 的逐字节比对确认（见 `ref/vanilla_baselines/REPORT.md`）。
- 1.19 目录覆盖 1.19 ~ 1.19.3（数据格式 10）。1.19.4 内容相同但格式为 12，当前没有对应目录。
- 1.21 目录覆盖 1.21 ~ 1.21.11：主包为 1.21 ~ 1.21.5 的内容（数据格式 48 ~ 94.1），`1_21_6_loot` 接管 1.21.6 起变化的 `piglin_bartering`（75 ~ 94.1），`1_21_9_noise` 接管 1.21.9 起变化的两张 `noise_settings`（82 ~ 94.1）。两个 overlay 需实机确认在主包之上生效。
- 1.21 系列跨越包元数据断代：1.21 ~ 1.21.8 读 `pack_format` 与 `supported_formats`，1.21.9 起读 `min_format` 与 `max_format`。主包与两个 overlay 条目都同时写两套并保持区间一致，需在 1.21、1.21.5、1.21.8、1.21.9、1.21.11 实机确认无「缺少 `pack_format`」或「区间不一致」报错。
